# ~*~ RETRO QUIZ ZONE ~*~

A nostalgic browser-based quiz game featuring retro 90s web design aesthetics, educational facts about technology, and interactive weather forecasts.

## Project Idea

**Creator:** Tedd

The idea for this retro-styled educational quiz platform was conceived and designed by Tedd, combining nostalgia for early internet design with modern web functionality.

## Features

### Quiz Categories (40 Questions Total)
- **♔ Chess** - Test your chess knowledge
- **⌨ Programming** - Code trivia from 1999
- **💾 IT & Tech** - Hardware and software questions
- **🎃 Horror** - Spooky movie facts

1. **📚 Retro Tech Facts (12 items)**
   - First Computer Virus (Creeper)

   Each language includes detailed history, features, frameworks, and official documentation links.

3. **🔥 Esoteric Programming Languages (6 items)**
   - Malbolge - The hardest language

### Weather Forecast
- **🌡️ Real-time Weather** - Shows current weather for your location using geolocation
- Displays temperature, conditions, wind speed, and humidity
- Uses Open-Meteo API and BigDataCloud for reverse geocoding

## Design Philosophy

The site embraces authentic 90s web design with:
- Retro color scheme (blues, yellows, greens)
- Courier New monospace font
- Ridge/outset borders
- Drop shadows
- Blinking text animations
- Marquee scrolling text
- Button press effects
- Classic "Best viewed in Netscape Navigator" footer

## Technology Stack

- **HTML5** - Semantic structure
- **CSS3** - Retro styling with modern features
- **Vanilla JavaScript** - No frameworks, pure JS
- **APIs Used:**
  - Open-Meteo Weather API
  - BigDataCloud Reverse Geocoding API
  - Browser Geolocation API

## How to Use

1. Open `index.html` in any modern web browser
2. Choose a quiz category to test your knowledge
3. Explore educational facts through the navigation buttons
4. Check the weather forecast for your current location
5. Enjoy the nostalgic retro design!

## Quiz Features

- Score tracking
- Question counter
- Instant feedback on answers (green = correct, red = incorrect)
- Back button to return to categories
- Play again option
- Percentage score calculation

## Educational Content

All facts include:
- Historical context
- Technical details
- Interesting trivia
- Clickable external links to Wikipedia, official documentation, and resources
- Links open in new tabs to preserve your quiz progress

## Browser Compatibility

Works on all modern browsers:
- Chrome/Edge
- Firefox
- Safari
- Opera

Requires JavaScript enabled for full functionality.
