# Spooky Dice Roller 🎲☠️

This is a fun and slightly unsettling Python console game where you roll a cursed dice.

## How to Run
1. Make sure you have Python 3 installed.
2. Open terminal or command prompt.
3. Navigate to this folder.
4. Run with:

```bash
python spooky_dice.py
```

## Features
- ASCII dice art
- Random spooky messages
- Infinite rolling... if you dare
