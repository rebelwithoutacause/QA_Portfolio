## 🎯 Overview

This presentation provides a comprehensive deep-dive into cyber security, covering everything from fundamental concepts to advanced attack techniques and defense strategies. It's designed for developers, security professionals, students, and anyone interested in understanding how to protect web applications from cyber threats.

The presentation features:
- **18 detailed slides** covering major security topics
- **30+ custom security icons** integrated throughout
- **Retro visual design** with bold colors and nostalgic styling
- **Real-world examples** and case studies
- **Interactive code demonstrations**
- **Practical defense strategies**

## 🛠️ Customization

### Changing Colors
Edit the CSS color variables at the top of the `<style>` section:
```css
/* Primary colors */
#e94560  /* Pink/Red - Change to your accent color */
#ff6b35  /* Orange - Change to your secondary color */
#fdc500  /* Yellow - Change to your highlight color */
```

### Adding Slides
1. Copy an existing slide `<div class="slide">...</div>`
2. Update the content inside
3. Update slide numbers in footer
4. Update total count in all slide footers

### Modifying Content
- Edit text within `<li>` tags for bullet points
- Modify code blocks within `<div class="code-block">`
- Update statistics in `<div class="stats-box">`
