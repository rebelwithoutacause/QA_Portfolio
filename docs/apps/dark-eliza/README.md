# Dark-ELIZA

Live: https://rebelwithoutacause.github.io/QA_Portfolio/apps/dark-eliza/

A creative coding experiment inspired by the original ELIZA (1966) and horror games like Harvester and Silent Hill. Not affiliated with either. Replies are generated by an AI model (via a proxy that keeps the API key private) — if it's unreachable, the page falls back to a small local response engine instead. Your conversation is kept in this browser's local storage so it persists between visits; use "Clear Session" to erase it.
