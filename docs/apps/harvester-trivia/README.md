# Harvester Trivia — Lodge Master Edition

Live: https://rebelwithoutacause.github.io/QA_Portfolio/apps/harvester-trivia/

A dark, gothic trivia game testing your knowledge of the cult horror game Harvester (1996) — a companion piece to [Dark-ELIZA](../dark-eliza/), also inspired by Harvester. Enter your name, answer multiple-choice questions about Harvest's characters and lore, and your score is saved to a local "Graveyard" (browser `localStorage`, per-device only — not an actual shared leaderboard).

Originally developed at [rebelwithoutacause/HarvesterTrivia](https://github.com/rebelwithoutacause/HarvesterTrivia); this copy is what's hosted live as part of the portfolio. Entirely client-side — vanilla HTML/CSS/JS, no backend, no API key.
